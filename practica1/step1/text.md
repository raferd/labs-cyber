## Comprobación inicial del escenario

El técnico le indica que los archivos del caso se encuentran en el
directorio:

```text
~/caso
```

Acceda a él:

```bash
cd ~/caso
```

Compruebe dónde se encuentra:

```bash
pwd
```

Y examine su contenido:

```bash
ls
```

Deberían aparecer cuatro directorios:

```text
documentos
correo
descargas
temporal
```
