# ¿Con quién se comunicaba el equipo?

## Direcciones, nombres, puertos y conexiones con relevancia jurídica

Durante el análisis del incidente, el equipo técnico entrega al departamento
jurídico varios datos relacionados con comunicaciones de red.

Aparecen términos como:

- dirección IP;
- nombre de equipo;
- DNS;
- TCP y UDP;
- puerto;
- conexión;
- servicio.

Para valorar correctamente esa información necesitamos saber qué significa
cada dato y, sobre todo, qué conclusiones podemos obtener de él.

Durante esta práctica analizaremos un pequeño registro de comunicaciones
y después crearemos una comunicación controlada dentro del propio laboratorio.

**Tiempo previsto: 35-40 minutos.**

La práctica está diseñada para poder completarse en menos de 45 minutos.
